# Account 360

Account, contacts, opportunities and open cases in one execution.

- Requires permissions: `sf.read.sales`, `sf.read.service`
- Uses mock-only adapters: no (works against a live org)

Run it against the mock org:

```bash
npm run example -- account-360
```

Or paste `program.ts` into the dashboard Playground, or send it to the `execute_code` MCP tool.
